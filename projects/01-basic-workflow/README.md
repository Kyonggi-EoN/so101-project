## 4. 어떻게 동작하는가

**로봇에게 "이렇게 움직여라" 를 코드로 알려주지 않는다.** 사람이 하는 걸 여러 번 보여주고, 그걸 따라 하게 만든다.

```
[1] 조종     사람이 leader 팔을 움직이면  →  follower 팔이 똑같이 따라온다
                    ↓
[2] 녹화     그 과정을 전부 기록한다
                    ↓  관절 각도 6개 + 카메라 영상, 초당 30번
[3/4] 학습   기록을 보고 "화면이 이럴 때 관절을 이 각도로" 를 배운다
                    ↓
[5] 추론     leader 팔 자리를 학습된 모델이 대신한다
```

**5번이 이 프로젝트의 정체다.** 사람이 잡던 leader 팔을 빼고, 그 자리에 학습된 모델을 넣는 것이다. follower 팔 입장에서는 달라진 게 없다 — 여전히 "누군가" 가 보내주는 관절 각도를 따라갈 뿐이다.
