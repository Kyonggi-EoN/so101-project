## 초당 30번 도는 루프

조종할 때나 학습된 모델을 돌릴 때나 **같은 루프가 초당 30번 반복된다.**

```
카메라 사진 + 현재 관절 각도  →  목표 관절 각도  →  모터로 전송
                                      ↑
                        조종: leader 팔에서 읽어옴
                        추론: 학습된 모델이 계산
```

follower 팔 입장에서는 목표 각도를 누가 보내주는지 알 필요가 없다. 사람이든 모델이든 똑같이 따라갈 뿐이다.
